Task 1: Display an Array Using Arrays.toString()
Question: Create an integer array and display all its elements.

Answer:
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};

        System.out.println(Arrays.toString(arr));
    }
}


Output:
[10, 20, 30, 40, 50]


Task 2: Sort Array Elements Using Arrays.sort()
Question: Sort the array elements in ascending order.
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {50, 10, 40, 20, 30};

        Arrays.sort(arr);

        System.out.println(Arrays.toString(arr));
    }
}


Output:
[10, 20, 30, 40, 50]


Task 3: Search an Element Using Arrays.binarySearch()
Question: Find the index of 30 in a sorted array.
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {10, 20, 30, 40, 50};

        int index = Arrays.binarySearch(arr, 30);

        System.out.println("Index: " + index);
    }
}


Output:
Index: 2


Note: binarySearch() requires the array to be sorted for reliable search results.

Task 7: Find the Sum Using Arrays.stream()
Question: Calculate the sum of all array elements using a stream.

Task 8: Find Maximum and Minimum Using Streams
Question: Find the largest and smallest values in an array.
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] arr = {45, 12, 78, 23, 9};

        int max = Arrays.stream(arr).max().getAsInt();
        int min = Arrays.stream(arr).min().getAsInt();

        System.out.println("Maximum: " + max);
        System.out.println("Minimum: " + min);
    }
}


Output:
Maximum: 78
Minimum: 9

Task 10: Compare Arrays Using Arrays.compare()
Question: Compare two integer arrays lexicographically.
import java.util.Arrays;

public class Main {
    public static void main(String[] args) {
        int[] a = {10, 20, 30};
